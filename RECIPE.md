# Benni

A Herdr window for running many coding agents across git worktrees. The left sidebar puts the sessions that need you, the ones at work and the ones that just finished on top as tinted cards, then lists every space (optionally grouped into workspaces such as work and personal) with a colored avatar, its repo, branch and ahead/behind, worktrees nested under their main checkout, and each space's agents and terminals beneath it. The tab bar opens a side panel per space: Files, Changes, a full git graph, or the repo's GitHub issues, where one click creates an `issue-N-...` worktree and starts Claude in it with the prompt already typed. Some labels are in French.

## How it behaves

- **Agent status** reads the same everywhere it shows. Working: a 12px spinner in `working` turning every 900ms. Blocked: a 14px rounded square in `blocked` at `26` alpha with a bold `!` (cards and rows), a `blocked` dot on tabs. Done: a 7px filled dot in `done` (6px on tabs). Idle: a 7px ring (1.5px, `idle`) and `muted` name. On the rail's numbered cells only blocked and done raise a `●`; the rail's session cells show every status mark.
- A session gets a card the moment it blocks or starts working; once done or idle its card moves to "Au repos" and drops off 24 hours after its last change. Cards sort newest change first. Clicking a card or an agent/terminal row focuses that pane (`pane.focus`). Clicking a card's issue line opens the issue on GitHub (tooltip "Ouvrir le ticket sur GitHub").
- **PR lifecycle** on carded sessions whose own branch is not `main`, `master` or detached: the PR is read with `gh pr list --head <branch>` from the main checkout every 30s while the window is in front (120s otherwise). Moving to a failing CI or to merged posts a notification (click focuses the agent). Buttons, only while the session rests: "Ouvrir la PR" when there is no PR and the branch has commits past `origin/HEAD`: `git push -u origin <branch>`, then `gh pr create --head` with the ticket title (else the last commit subject) and a body of "Closes #N" and the commit subjects. "Corriger la CI" when an open PR fails: reads `gh run view <run> --log-failed` for each failed Actions run (last 80 lines each, timestamps and colors stripped) and sends the failing checks and logs to the agent with `hc send`; then "Logs de CI envoyés à l'agent" until the PR head changes. "Nettoyer" when merged and the session is in a linked worktree, clicked twice within 4s: refuses uncommitted changes, closes the spaces in that worktree and waits for their terminals, `git worktree remove`, then `git branch -D` if the local branch is the PR head (else `-d`, kept and reported if it holds other commits); the outcome is a notification, as the card is gone. On `main` or `master` instead (read with `git status --porcelain` and `git rev-list --count @{upstream}..HEAD`): "Commit & push (N)" when files changed, which asks the agent with `hc send` to commit them with clear messages and push (then "Commit et push demandés à l'agent" until the next git read), else "Push ↑N" when commits are not on the upstream, which runs `git push`. A carded session's git is read again as soon as its agent changes status.
- A session's issue number comes from its branch `issue-42-...`, else a tab named `#42`, else `#42` in its title; the title is read with `gh api` from the main checkout.
- A Claude session started in a folder that holds `bot.json` shows a bot icon instead of Claude's mark.
- **Spaces**: click selects, right-click opens Herdr's space menu, press and drag onto another space of the same machine reorders (the dragged row fades to 50%, a 2px `accent` line marks the drop). The chevron folds one space's sessions (tooltips "Replier" / "Déplier"); the header button folds or unfolds all ("Tout replier" / "Tout déplier"). Folds are remembered. The `+` runs `space.new`.
- **Workspaces**: a click on a header folds it (remembered), right-click opens the settings, its `+` makes a space that joins it (the first new space within 10s). Dragging a space onto a header, an empty slot, or a space in another workspace moves it there (dropping on a space also reorders when on the same machine), with the worktrees nested under it. The Spaces header's `+` puts the new space in the active space's workspace; spaces made any other way land in the default one. A worktree nested under its main checkout always shows in that checkout's workspace. Agent navigation follows the shown order; `space.select` indexes and `space.next` keep Herdr's order.
- **Settings**: add (Enter or "Ajouter"), rename (`✎` or double-click, Enter saves, Esc cancels), reorder with `↑`/`↓`, delete with an inline confirmation ("Supprimer « X » ? Ses N spaces iront dans « Default »."). The default workspace (id `default`, "Default") holds every space without one; it can be renamed, not deleted, and is recreated if missing. Esc closes the dialog.
- The list keeps worktree spaces right under their main checkout by moving spaces itself (`space.move`), and scrolls the active space into view when it changes.
- Git info refreshes when a space changes folder, when a command or an agent's turn ends in that repo, when a machine comes back, when files change in a local repo's git folder, and every 60s for listed repos while the window is in front (six places at a time).
- **Machines**: a header click folds that machine. A machine needing login shows "needs a login: run `hc machine login <name>`" with a Copy button. A machine that was rebuilt shows "Connect", which removes and re-adds it with `hc`. A `⚠` warns that agents stop on disconnect and opens the add-machine dialog.
- **Tabs**: click selects, double-click renames, drag onto another pill moves it, right-click opens Herdr's tab menu, the wheel over the bar steps to the previous or next tab, the cross closes the active tab, `+` opens Herdr's new menu (250 by 512px).
- **Side panel**: a panel button opens that block (or closes the panel if it is already showing). The choice is remembered per space: switching spaces restores that space's panel, or closes it if the space never had one.
- **Issues**: refreshes every 30s while shown and the window is visible, from the focused pane's folder (up to 100 open issues). "Mes issues" keeps only issues assigned to you. Clicking a row expands it: label pills in each label's color, "Assignée à" with "M'assigner" / "Me retirer", "Lancer Claude" (or "Ouvrir la session" when its worktree exists), "Voir sur GitHub", the PR with each check as a clickable row (pending ones animate `◐◓◑◒`). Errors show in `ansi1` ("Lancement impossible : ...").
- **Lancer Claude** creates branch `issue-<N>-<slug>` (title without accents, lowercased, at most 40 characters) as a worktree in Herdr's worktree folder (`worktrees.directory`, default `~/.herdr/worktrees`) under `<repo>/<branch>`, based on `origin/HEAD` after fetching it (else `HEAD`), then opens a new space there with tab `#N` running `claude --plugin-dir <claude-draft>` with `CLAUDE_PROMPT_DRAFT="Traite l'issue <url>"`. Claude starts through the user's `$SHELL` (fish: `fish -c`; bash and zsh: interactive `-ic`, so `~/.bashrc` or `~/.zshrc` loads), so a `claude` function or alias there applies; any other shell runs the `claude` binary directly. The small plugin puts that text in Claude's prompt box without sending it.
- **Worktrees à nettoyer**: every linked worktree of the repo (not only `issue-N-...` ones, and whether or not a session card shows) has its PR read with the issues; a merged or closed PR is not asked again until the repo changes. "Nettoyer" or "Nettoyer les N" opens an inline confirmation (border `ansi1` at `55`): "Supprimer le worktree et la branche X ?", the spaces that will close, and in `ansi1` how many agents working or blocked there will stop; "Supprimer" (`ansi1`) or "Annuler". Worktrees go one at a time: `git status --porcelain` again (changes stop that one), `space.close` on each space whose folder or a pane is inside it, a wait of up to 10s for their terminals to end, `git worktree remove` (`git worktree prune` when the folder is gone), then `git branch -D` if the branch still points at the PR head, else `-d`, which keeps a branch holding other commits. A line under the rows reports "N nettoyés · branche gardée, commits absents de la PR : X · échec : Y (why)".
- **Graph**: double-click a branch label to check it out; right-click a commit, label, the uncommitted row or a Manygit repo for git actions (checkout, branch, tag, merge, rebase, cherry-pick, revert, reset soft/mixed/hard, push, pull `--ff-only`, stash, commit, delete). Items ending in `…` ask in a dialog first (danger ones in `ansi1`); every action except fetch first checks that HEAD and the branch have not moved since the menu opened. It follows the focused pane's folder, watches local repos and polls remote ones every 15s.

## Watch out

- **Network**: `git-graph` asks `api.github.com/repos/rabeeh-ta/herdr-git-graph/releases/latest` at most once a day (no token); "Stop checking" in its update window, or `CHECK = false` in `update.js`, turns it off. `gh-issues` and `benni-spaces` reach GitHub through `gh`.
- **Programs and files**: the mods run `git`, `gh`, `find`, `test`, `sh` and `hc` (plus `wslview`, `explorer.exe` or `xdg-open` to open links under Linux), on remote machines too. `gh-issues` reads Herdr's `settings.json`, and for a space on another machine writes the plugin to `~/.cache/herdr-gh-issues/claude-draft` there (a local space uses the mod's own `claude-draft/` in place). Graph actions really change repos: reset hard, delete branch, delete remote branch, push.
- **Assumptions**: `gh` installed and logged in. If `mise` exists, `gh` runs under `mise exec` so a folder's `GH_TOKEN` picks the account. Links use the app's own opener on macOS and Windows; under Linux the mods detect WSL from `/proc/sys/kernel/osrelease` and hand the URL to `wslview` (if installed) or `explorer.exe`, else to `xdg-open`. Claude Code must be on the space's machine for "Lancer Claude". The issue branch convention `issue-<N>-...` links worktrees, sessions and cards.
- **Left out of the repo** because they are generated: `gh-issues/claude-draft/.claude-plugin/types/` (its `tsconfig.json` extends it, so editor type checks fail until it exists) and every mod's `gpui-kit.d.ts` (the `jsconfig.json` files expect one).
- **French UI**: card sections "En cours" / "Au repos", fold tooltips, folded pill tooltips, all of `gh-issues`, and the launch prompt "Traite l'issue <url>". "Needs you", "Spaces" and everything in `git-graph` are English.
- **Names are wired into paths**: `tabs-graph` draws `mods/git-graph/icons/graph.svg`, `mods/gh-issues/icons/issue.svg`, `mods/files/file.svg`, `mods/changes/changes.svg`; `benni-spaces` draws `mods/gh-issues/icons/issue.svg` and its own `mods/benni-spaces/*.svg`; `gh-issues` finds its plugin at `<appHome>/mods/gh-issues/claude-draft` and recognises its own block by `mod === "gh-issues"`. Renaming a mod means renaming these.
- **The rail on macOS**: `workspace-chrome` hides its fold button on the macOS rail and expects the agents list to offer the way back. This layout has no agents list and the sidebar is not resizable, so `benni-spaces` must draw its own `»` on the rail; without it the sidebar stays narrow.
- `tabs-graph` lacks what the current shipped `tabs` added since: any wheel event of 1px or more steps one tab (a touchpad swipe skips several), the active tab is not scrolled into view, and a corrupt `panels` entry in its localStorage throws at start.
- `tabs-graph` panel ids are fixed: stack `panel-body`, column `panel`, children `files`, `changes`, `graph`, `issues`. The tab bar's left inset clears the macOS traffic lights from `traffic_lights[0]` and the sidebar width.
- The spaces list reorders spaces by itself; a hand order that splits a worktree from its main checkout is undone.
- Limits: 100 open issues, 3 assignee circles, 300 commits per page in the graph, Manygit depth 1 to 5 (default 3) and at most 500 repos, never scanning a home folder or above.
- **Workspace code is repeated**: Herdr refuses imports between mods, so `benni-spaces` and `benni-settings` each carry the same `readWorkspaces` (key, default workspace, unknown ids fall back to `default`). Change both together. Never prune `of` from `spaces()`: spaces of a machine that is loading or offline would lose their workspace.
- The space named `~` gets no stored color (it shows `ansi6`).
- `git-graph` checks the app version to decide whether lists zoom themselves (0.1.12 and later).

## Done when

- The sidebar shows the brand row, then "Spaces" with fold-all and `+`; each space has an 18px avatar in one of the six colors, and a worktree space appears under its main checkout with a branch icon.
- A space whose branch is ahead of its upstream shows `↑N` in `ansi2` after its name; `main` and `master` are not printed.
- Starting an agent that works adds an "En cours" card with a spinner; when it asks for permission the card moves to "Needs you" with a `!` mark; when it finishes it shows under "Au repos" with its elapsed time.
- Clicking a card focuses that agent's pane.
- Folding a space hides its session rows and shows a count pill per CLI; the state survives a restart.
- Folding the sidebar turns the list into numbered cells, shows a cell per carded session above them (click focuses it), and the `»` at the bottom brings the sidebar back, on macOS too.
- The gear opens the settings; turning "Utiliser les workspaces" on and adding "Perso" shows "Default" and "Perso" headers in the sidebar; dragging a space onto "Perso" moves it there, and it is still there after restarting Herdr. Deleting "Perso" sends its spaces back to "Default"; turning the switch off brings back the flat list.
- Tabs show spinners and dots for their agent, rename on double-click and reorder by drag.
- The Graph button opens the panel on the git graph of the focused folder; switching to another space and back restores that space's panel choice.
- In a GitHub repo, the Issues button lists open issues; "Mes issues" filters to yours; expanding one and pressing "Lancer Claude" creates `issue-<N>-<slug>` under the worktree folder and opens a space with tab `#N` where Claude starts with "Traite l'issue <url>" typed but not sent.
- Back in the Issues list, that issue now shows a "session" badge and "Ouvrir la session" selects its space.
- `herdr-app check` passes for `benni-spaces`, `benni-settings`, `benni-toast`, `tabs-graph`, `gh-issues` and `git-graph`, and `layout.switch {name: "benni"}` shows the window.
